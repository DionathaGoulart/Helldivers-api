curl https://helldivers-api.dionatha.com.br/v1/weapons/ar-23-liberator.json

> JavaScript

const res = await fetch(
  "https://helldivers-api.dionatha.com.br/v1/query/weapons?category=primary&trait=light-armor-penetrating",
);
const { meta, data } = await res.json();
console.log(meta.total, data[0].name);

> Collections

WARBONDS.JSON — warbonds WEAPONS.JSON — weapons STRATAGEMS.JSON — stratagems ARMORS.JSON — armors HELMETS.JSON — helmets CAPES.JSON — capes ARMOR-SETS.JSON — armor sets BOOSTERS.JSON — boosters PASSIVES.JSON — armor passives WEAPON-TRAITS.JSON — equipment traits PLAYER-CARDS.JSON — player cards EMOTES.JSON — emotes and poses PATTERNS.JSON — patterns TITLES.JSON — titles

Each collection answers /v1/<collection>.json, /v1/<collection>/<id>.json, .csv, facets such as /v1/weapons/by-warbond/steeled-veterans.json and a JSON Schema under /v1/schemas/.

CACHING.TXT
  • Every response carries an ETag. Send If-None-Match and take the 304 — it costs you nothing and keeps the API free for everybody.
  • image.url is content-hashed and served immutable: cache it forever, and re-read the entity to notice a new picture.
  • Static lists, items, facets and images are plain files, free and never limited. Reach for /v1/query/* and /v1/search only when no file fits: they run code and count requests per client. Keeping a local copy? Sync /v1/all.json once a day.
  • X-Data-Version names the dataset a response was built from; the same value is in meta.dataVersion and in the changelog.
  • Enums are open: a new warbond can add a value. Ignore what you do not know instead of failing.
