NEW.JS

> Two static files, no limit

const all = await get("/all.json");       // { weapons: [...], stratagems: [...], ... }
const log = await get("/changelog.json"); // newest entry first
const since = new Date(Date.now() - 30 * 86_400_000).toISOString().slice(0, 10);

const upcoming = Object.values(all).flat().filter((item) => item.upcoming);
const warbonds = all.warbonds.filter((warbond) => warbond.releaseDate >= since);
const added = log
  .filter((entry) => entry.date >= since)
  .flatMap((entry) => entry.changes.filter((change) => change.kind === "added"));

get is the helper of the examples. This page runs the same lines, then shows each item once: a new warbond keeps what it sells, and what is announced is not repeated as added. Sync /v1/all.json once a day and your site can do the same.
