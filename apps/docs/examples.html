The API in use

Everything below comes from the API while you read: five items of every kind, fetched from the same static files any site or bot would use, and laid out like a normal site. Press Show requests to see what is behind each section — the code, every request it made and the JSON that came back.

Fetching

Open docs
GET.JS

> The one helper every section uses

const API = "https://helldivers-api.dionatha.com.br";
const get = async (path) => (await (await fetch(`${API}/v1${path}`)).json()).data;

// Images are paths on the same host: `${API}${item.image.url}`

Every response is { meta, data }; get keeps data. Paste both lines in a browser console and every snippet on this page runs as is. All of it hits static files: no key, no signup and no rate limit.

> Armor sets

A complete look: helmet, armor, cape and the armor's passive. The set only holds ids, so each part is one more request.

ARMOR-SETS.JS 
const set = await get("/armor-sets/sc-34-infiltrator.json");
const [armor, helmet, cape] = await Promise.all([
  get(`/armors/${set.armorId}.json`),
  get(`/helmets/${set.helmetId}.json`),
  get(`/capes/${set.capeId}.json`),
]);
const passive = await get(`/passives/${armor.passiveId}.json`);
// …the same for each of the five sets

> Weapons

One item per request. Traits are ids too; a trait two weapons share is fetched once.

WEAPONS.JS 
const weapon = await get("/weapons/ar-23-liberator.json");
const traits = await Promise.all(
  weapon.traitIds.map((id) => get(`/weapon-traits/${id}.json`)),
);
// weapon.firearm: fire rate, magazine, reload · weapon.throwable: fuse, carry
// weapon.attacks[0]: damage and armor penetration

> Stratagems

One item per request, input code included. The full list is large, so ask for the items you show.

STRATAGEMS.JS 
const stratagem = await get("/stratagems/eagle-500kg-bomb.json");
stratagem.code;        // ["up", "right", "down", …]
stratagem.cooldownS;   // seconds
stratagem.callInTimeS; // seconds
stratagem.uses;        // a number or "unlimited"

> Warbonds

Each warbond lists its pages and every item on them, with its medal cost and a ref to the item's own collection.

WARBONDS.JS 
const warbond = await get("/warbonds/cutting-edge.json");
const items = warbond.pages.flatMap((page) => page.items);
// item.ref: { collection, id } → get(`/${item.ref.collection}/${item.ref.id}.json`)

> Boosters

A short list: one request brings every booster, and the page picks five in memory.

BOOSTERS.JS 
const boosters = await get("/boosters.json");
const picks = ["vitality-enhancement", "stamina-enhancement", "muscle-enhancement",
               "hellpod-space-optimization", "uav-recon-booster"];
const shown = picks.map((id) => boosters.find((booster) => booster.id === id));

> Player cards

A facet: a file per warbond, already filtered. This one is Helldivers Mobilize.

PLAYER-CARDS.JS 
const cards = await get("/player-cards/by-warbond/helldivers-mobilize.json");
const shown = cards.slice(0, 5);

> Emotes

The victory-pose facet: every emote you can end a mission with.

EMOTES.JS 
const poses = await get("/emotes/by-kind/victory-pose.json");
const shown = poses.slice(0, 5);

> Patterns

The weapon-scope facet: camouflage for your primaries.

PATTERNS.JS 
const patterns = await get("/patterns/by-scope/weapon.json");
const shown = patterns.slice(0, 5);
// pattern.variants: one image and one source per thing it paints

> Titles

The rank facet, sorted by the level that earns each one: the first five a Helldiver gets.

TITLES.JS 
const ranks = await get("/titles/by-kind/rank.json");
const shown = ranks.sort((a, b) => a.levelEarned - b.levelEarned).slice(0, 5);

These are the static files: lists, items and by-* facets, free and never limited. For filters they do not cover there is /v1/query/*, and /v1/search for names; both are in the reference and count requests per client.
