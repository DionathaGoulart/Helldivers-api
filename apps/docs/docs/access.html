Limits and access

Every static file is free and never limited: lists, items, facets, CSV, images, schemas and /v1/all.json, the whole catalog in one file. Only /v1/query/* and /v1/search run code, and they count requests per client.

> Query and search limits

ANON
10 / 60 s

Per IP. Nothing to do: enough to try the API out.

ORIGIN
10 / 10 s

Per visitor of an allowlisted site: each browser gets its own budget.

KEY
20 / 10 s

Per key, for a server, a bot or a script.

Past the limit the answer is a 429 with Retry-After. Every query and search response names its tier in X-API-Tier, its limit in RateLimit-Policy and what is left in RateLimit ("anon";r=7;t=42: 7 requests left, the window starts over in 42 s). Windows are fixed and counted per client worldwide; floods are blocked at the edge whatever the tier.

On top of the tiers, query and search share one budget a day across every client: 80000 requests for anon, origin and key, then 503 until 00:00 UTC. RateLimit shows what is left in its "daily" item, and X-API-Warning appears once fewer than 15000 are left.

SYNC.JS

> No limit at all: sync once a day

The data changes at most once a day. A bot or a site that keeps its own copy never needs query or search: check /v1/meta.json (a 304 most of the time), download /v1/all.json when dataVersion moves, and filter in memory. 

let version = null;
let catalog = null;

async function sync() {
  const meta = await (await fetch("https://helldivers-api.dionatha.com.br/v1/meta.json")).json();
  if (meta.dataVersion === version) return;
  const res = await fetch("https://helldivers-api.dionatha.com.br/v1/all.json");
  catalog = (await res.json()).data; // { weapons: [...], stratagems: [...], ... }
  version = meta.dataVersion;
}

await sync();
setInterval(sync, 60 * 60 * 1000); // hourly is plenty
const primaries = catalog.weapons.filter((w) => w.category === "primary");
KEYS.TXT

> Using a key

curl -H "Authorization: Bearer hd2_…" \
  "https://helldivers-api.dionatha.com.br/v1/search?q=liberator"
  • Keep it on a server. A key in browser code is a public key: anyone can copy it and spend its budget. Sites use the allowlist instead.
  • A wrong or revoked key gets a 401, not the anonymous limits — drop the header to go back to them.
  • A lost or leaked key is revoked and replaced, never recovered.
ASK.TXT

> Asking for more

  • A site (requests from the browser): open an access request with the domain and what the site does. Once approved, the domain is added to the allowlist and ships with the next deploy.
  • A key (a server, a bot, a script): email api@dionatha.com.br with the project, a link if there is one, and roughly how many requests a day. The key comes back by email.
  • Access is for non-commercial projects, like the rest of the API (CC BY-NC-SA 4.0).
